# v0.5.0 官网发布设计

## 目标

将 Fomo Live Feed 官网与已发布的 `v0.5.0` 保持一致，并部署到现有 Vercel 生产域名。

## 内容范围

- 全站当前版本与下载链接使用 `v0.5.0`。
- 首屏明确 Fomo 与 Pump 双来源，不暗示自动交易或云端监控。
- 产品示例展示来源筛选、Pump 状态与紧凑信息卡能力。
- 功能区、使用步骤和 FAQ 说明对应来源页面必须保持登录并打开。
- 更新日志新增 `v0.5.0`，保留 `v0.1.0` 至 `v0.4.0`。
- 发布到现有 Vercel `website` 项目，并继续使用 `fomolivefeed.online`。

## 验证

- 对照 `CHANGELOG.md` 与 `package.json` 检查官网文案和版本号。
- 首页自动化测试覆盖版本、下载链接、双来源与历史版本。
- 检查 JavaScript 语法、CSS 结构和 Git diff。
- 确认 GitHub Release `v0.5.0` 及 Chrome ZIP 资产存在。
- Vercel 返回生产部署 `READY` 且域名完成别名切换。

## 首页可见性修正

- 首屏主标题直接表达 `Fomo + Pump 双来源`，而不是只在辅助文字中出现。
- 默认实时动态演示同时显示 Fomo 与 Pump 的连接状态、来源徽标和各一条示例动态。
- 筛选演示明确显示 `全部来源 / 仅 Fomo / 仅 Pump` 与买入金额范围。
- 第一张功能卡以“两个来源，一条信息流”为核心，展示按时间混排和来源标签。
- 功能说明明确交易身份合并去重与买入金额筛选。
- 测试按首屏、实时动态面板、筛选面板和功能区分别断言。
