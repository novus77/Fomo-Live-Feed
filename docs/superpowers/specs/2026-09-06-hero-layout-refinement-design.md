# 首屏布局精修设计

## 目标

修正首屏标题在桌面端意外折成三行的问题，并将“示例界面”标签与右侧产品演示框明确分层，避免标签压住演示内容。

## 设计

- 标题保留原文，拆成两个不可在桌面端内部换行的短语：`你关注的交易员，` 与 `刚刚做了什么？`。
- 桌面端通过标题行包装元素和 `white-space: nowrap` 保持两行；移动端恢复自然换行，避免窄屏溢出。
- “示例界面”作为产品舞台的独立顶部标题行，不再绝对定位覆盖浏览器框。
- 产品舞台使用纵向排列和明确间距，使标签位于演示框上方且右对齐。

## 验证

- 自动化测试确认标题包含两个独立行包装元素。
- 自动化测试确认示例标签位于浏览器框之前，并处于独立标题容器中。
- 运行首页测试、JavaScript 语法检查与 CSS 括号检查。
