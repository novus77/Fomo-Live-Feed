# Live Buy Sound Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Play one bundled sound for every first-seen live buy when the global, default-off setting is enabled, including while the Side Panel is closed.

**Architecture:** The live ingestion path invokes an injected best-effort notifier only after a new buy is persisted; recovery never invokes it. The notifier reads the latest settings and delegates playback to a single-flight Chrome Offscreen Document that restarts one bundled audio element for every command.

**Tech Stack:** TypeScript, WXT, Chrome MV3 Offscreen API, React, Zod, Vitest, Testing Library, Playwright

export interface OffscreenAudioChrome {
  runtime: {
    getContexts(query: { contextTypes: ['OFFSCREEN_DOCUMENT']; documentUrls: string[] }): Promise<unknown[]>;

    sendMessage(message: ExtensionMessage): Promise<unknown>;

- [ ] **Step 4: Implement the offscreen entrypoint**

`index.html` contains only `#app` and the module script. `main.ts` creates exactly one audio element:

```ts
const audio = new Audio(browser.runtime.getURL('/audio/buy-alert.mp3'));
audio.preload = 'auto';

browser.runtime.onMessage.addListener((candidate) => {
  const parsed = parseExtensionMessage(candidate);
  if (!parsed.ok || parsed.message.type !== 'sound.playBuy') return undefined;
  audio.pause();
  audio.currentTime = 0;
  void audio.play().catch(() => {});
  return undefined;
});
```

Add a short royalty-free/local-generated MP3 under 100 KB; record its provenance in a comment in the plan execution notes or replace it with a generated sine/chime asset owned by the repository.
